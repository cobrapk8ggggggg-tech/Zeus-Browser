# خريطة نطاق النقل

المقارنة تخص عينة Ascent 1.0.25 المفحوصة، وبناء ZEUS عند بدء هذا الفرع. هذا الفرع ينقل مسار صور المواقع؛ لا يعلن نقل كل التطبيق.

| قدرة Ascent | وضعها في هذا الفرع |
|---|---|
| OCR محلي سريع للنص اللاتيني والكوري والياباني والصيني | ML Kit مضمّن في بناء الجهاز؛ Vision بديل المحاكي المعلن |
| Paddle / ONNX وقواميس متعددة الأبجديات | حزم عامة ببصمات ومراجعات ثابتة، واستدلال ONNX فعلي |
| صور طويلة ونوافذ متداخلة وسياق عند حدود الصور | تنفيذ WebKit مستقل، أولوية للمرئي وعدم عبور صور غير محملة |
| تبديل الأصل وإيقاف الترجمة واستكمالها | منفذ مع مراجعة الصورة وجيل الجلسة وعزل WKContentWorld |
| Google / Microsoft / MyMemory | محولات بدون مفتاح؛ تحقق حي من البروتوكولات |
| Yandex / Papago / DeepL / Caiyun / Anthropic | محولات API تحتاج مفاتيح المستخدم؛ ليست نسخة من بروتوكولات الويب الخاصة بـAscent |
| مزودو ZEUS الحاليون | يعاد استخدام الخدمات والحسابات مع اختيار مستقل للصور |
| تشكيل العربية والخطوط والحجم واللون | CoreText مع استيراد الخطوط وإعادة الرسم من المراحل المحفوظة |
| تخزين مراحل OCR والترجمة والرسم والتصفح الخاص | منفذ، مع عزل البروفايل وحدود مساحة وحذف نتائج البروفايل المحذوف |
| ترجمة محلية بواسطة llama.cpp | محرك مضمّن واستيراد GGUF؛ جودة نموذج الترجمة تحتاج قياسًا فعليًا |
| تنظيف الفقاعات والخلفيات | أقنعة موضعية وخلفية مستنتجة؛ لا يطابق كل تنظيف Ascent |
| كشف النص المائل/المنظور والتجميع المتقدم | صناديق محاذية للمحاور ودوران للنص الطويل؛ التكافؤ الكامل غير منجز |
| خدمة Android المعزولة لفك الصور وSharedMemory | البديل هنا مفكك C++ محدود الصفوف داخل تطبيق iOS؛ ليس عزل عملية مماثلًا |
| كتالوج نماذج قابل للتحديث عن بعد | كتالوج ثابت موثوق ضمن توقيع التطبيق؛ تحديث عن بعد بتوقيع منفصل غير مضاف |

## ميزات Ascent التي تبقى خارج ZEUS أو مختلفة جوهريًا

- قارئ المانجا المستقل: مكتبة العناوين والفصول وسجل التقدم والتصنيفات ومتابعة الفصول.
- منظومة مصادر المانجا وإضافاتها وأجزاء QuickJS التابعة لها.
- تنزيل الفصول وقوائم مهامها ونسخ احتياطي خاص بمكتبة القارئ.
- مسار الفيديو الأصلي والكشف عن الترجمات والترجمة المتزامنة مع التشغيل.
- تنفيذ Chromium/Blink/V8 وبروكسيه وتفاصيل Shields الخاصة به؛ ZEUS يحتفظ بـWebKit ومانع الإعلانات وخدماته الحالية.

وجود قارئ مقالات أو تنزيل ملفات أو JavaScript مستخدم في ZEUS لا يساوي تلك المنظومات المتخصصة. تطويرها يحتاج نطاقًا منفصلًا. لم تنقل إعلانات Ascent أو شروط تنزيله المكافأة أو آليات الترخيص أو مفاتيح المطور.

## ما يمنع إعلان التكافؤ الآن؟

إثبات البناء واجتياز اختبارات WebKit وOCR الصناعية لا يقيس جمال تنظيف الخلفية أو صحة السياق أو سرعة أجهزة المستخدم. معيار القبول يتطلب مجموعة مانهوا حقيقية متطابقة، قياسات Ascent وZEUS على أجهزة فعلية قديمة وحديثة، ومراجعة مرئية مستقلة للعربية. أداة المقارنة ترفض غياب هذه الأدلة؛ لا تنشئ نتائج افتراضية.
